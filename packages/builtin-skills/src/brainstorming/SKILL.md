# Brainstorming

Use this skill before making design or behavior changes.

## Workflow

1. Read the current project context.
2. Ask one clarifying question at a time.
3. Propose 2 to 3 approaches with trade-offs.
4. Present a concise design and get approval before implementation.

## Rules

- Do not write code or start implementation while still exploring the design.
- Keep the scope focused on the requested change.
- If the task is large, break it into smaller parts first.
