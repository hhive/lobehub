# Executing Plans

Use this skill to carry out a saved plan exactly.

## Workflow

1. Read the plan.
2. Review it critically for gaps or conflicts.
3. Stop and ask if the plan is blocked or unclear.
4. Execute each step in order.
5. Verify each step before moving on.

## Rules

- Do not improvise beyond the approved plan.
- If the plan needs changes, return to planning.
- Keep the execution checkpointed and test-driven.
