# Requesting Code Review

Use this skill when the current change should be reviewed by another engineer or by a review-oriented pass before merge.

## Workflow

1. Summarize the change in one short paragraph.
2. Point reviewers to the files or behavior that changed.
3. Ask for findings first, not a general summary.
4. Call out risk areas and test coverage.

## Review focus

- Correctness and regressions
- Missing tests
- Behavioral drift from the request
- Upgrade or deployment risk
