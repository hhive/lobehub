# Writing Plans

Write a concrete implementation plan that another engineer can execute with minimal context.

## Requirements

- List exact files to touch.
- Break work into small actionable steps.
- Include tests and verification commands.
- Keep the plan focused on one deliverable.

## Output

Save the plan under `docs/superpowers/plans/` with a date-based filename.
